# Semantic Layout Demo

This repository contains a simple HTML + CSS project showcasing the use of **semantic HTML5 elements** (`header`, `main`, `article`, `footer`) combined with responsive styling. It demonstrates how to structure a webpage with clear semantics while applying modern CSS techniques for layout and design.

## 📂 Project Structure
- **index.html**  
  The main HTML file using semantic elements to organize content blocks such as a header, articles, and footer.
- **styles.css**  
  The stylesheet providing layout, typography, and responsive image handling with floats and clear fixes.

## ✨ Features
- Semantic HTML5 layout (`header`, `main`, `article`, `footer`)
- Clear float handling for text wrapping
- Accessible footer with social media links
- Simple, clean design with rounded corners and section spacing
